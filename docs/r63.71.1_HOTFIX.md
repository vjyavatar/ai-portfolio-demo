# r63.71.1 — Hotfix Deploy

This is a code-only hotfix on top of r63.71. The smoke test caught two
bugs in the EDGAR index parser; this fixes them.

**Render redeploy is OPTIONAL.** No `api.py` or frontend changes —
the deployed web service is unchanged. You only need to:

1. Replace your local `celesys_v4_FINAL_DEPLOY` directory with this zip
2. Run migration 002 (one time, ~1 second)
3. Re-run the smoke test

If you want everything in git history, push and let Render redeploy
in the background. But it's not blocking.

---

## Step 1 — Run migration 002

This widens `ticker` columns from VARCHAR(10) to VARCHAR(20). The
migration is idempotent — re-running is a no-op.

**From your laptop:**

```powershell
cd celesys_v4_FINAL_DEPLOY
$env:NEON_DATABASE_URL = "postgresql://...your...pooled...connection..."
python db\migrations\002_widen_ticker.py
```

Or from Render shell:

```bash
python db/migrations/002_widen_ticker.py
```

Expected output:

```
Connecting to: ep-crimson-hill-ajol6ml6.c-3.us-east-2.aws.neon.tech
  ALTER holdings.ticker: VARCHAR(10) -> VARCHAR(20)
  ALTER cusip_ticker_map.ticker: VARCHAR(10) -> VARCHAR(20)
  ALTER mapping_overrides.ticker: VARCHAR(10) -> VARCHAR(20)
OK — 3 altered, 0 skipped in 0.4s
```

If you re-run it later you'll see `SKIP ... already VARCHAR(20)` for
each — that's the idempotence behavior.

## Step 3 — Verify in Neon

```sql
-- Should show 5
SELECT COUNT(*) FROM filings;

-- Should be in the few hundreds to low thousands
SELECT COUNT(*) FROM holdings;

-- Resolution rate — should be > 90%
SELECT
  COUNT(*) FILTER (WHERE confidence = 'figi')       AS resolved,
  COUNT(*) FILTER (WHERE confidence = 'unresolved') AS unresolved,
  ROUND(100.0 * COUNT(*) FILTER (WHERE confidence = 'figi') / NULLIF(COUNT(*), 0), 1) AS resolved_pct
FROM cusip_ticker_map;

-- Spot-check: top 10 holdings by value
SELECT ticker, issuer_name, value_usd, shares
FROM holdings
WHERE ticker IS NOT NULL
ORDER BY value_usd DESC
LIMIT 10;

-- Job log — should show status='ok'
SELECT job_name, status, filings_processed, holdings_inserted,
       cusips_resolved, started_at, completed_at
FROM ingestion_log
ORDER BY id DESC LIMIT 5;
```

If the top-10 holdings show familiar mega-cap tickers (AAPL, MSFT,
NVDA, AMZN, GOOGL, BRK/B, TSLA, etc.) with multi-billion-dollar values,
the pipeline is verified end-to-end.
