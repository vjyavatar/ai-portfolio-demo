## What this scanner is — and isn't

**It IS:** an institutional positioning intelligence layer based on
SEC 13F data. It tracks Q-over-Q changes in institutional capital
allocation across the top 100 filers (BlackRock, Vanguard, Citadel,
etc., comprising the bulk of US institutional capital). The score
combines share-count delta, filer-count delta, persistence, and
concentration metrics — each z-score normalized against the
universe.

**It IS NOT:** a real-time signal. 13F data is filed quarterly
within 45 days of period end, so the latest signal lags by up to
4 months. This is fundamental to 13F as a data source, not a flaw
of the implementation.

**Best use:** confirming/disconfirming a thesis on a stock. "Is
LLY's institutional ownership growing or rolling over?" "Are funds
exiting META on the AI capex story?" Etc.

## Troubleshooting

**Endpoint returns 500:** Check Render logs for the import error.
Likely the `psycopg`/`psycopg_pool` deps didn't install cleanly.
Re-deploy from clean cache.

**`results: []` even though backfill ran:** Backfill may have only
populated one quarter. Check:
```sql
SELECT COUNT(DISTINCT period_of_report) FROM filings;
```
Need ≥2 to compute Q-over-Q deltas.

**UI shows "Computing..." forever:** Check browser console for
fetch errors. Endpoint may be returning 5xx — check `/health` first.

**All tickers show same score (e.g., 50.0):** Means scoring engine
ran but found no Q-over-Q variance. Likely all tickers in the DB
have data in only one quarter. Verify multi-quarter coverage.
